# Lluerna

Lluerna és un joc de laberint i persecució per a un jugador. Ets una cuca de llum en un laberint de bardisses: has de recollir totes les gotes de rosada mentre tres aranyes et persegueixen.

## Com jugar

Obre `index.html` al navegador. No cal instal·lar res: és HTML, CSS i JS sense dependències.

## Controls

- Fletxes o WASD: moure's
- Espai: començar
- P: pausa

## Regles

- Les flors de lavanda espanten les aranyes durant uns segons, i en aquest temps les pots atrapar per obtenir punts extra.
- Hi ha un túnel lateral per passar d'un costat a l'altre del laberint.
- Tens 3 vides.
- Cada nivell és més ràpid que l'anterior.
- El rècord es guarda al navegador.

## Les tres aranyes

- **Teranyina**: et persegueix directament.
- **Talla-pas**: intenta tallar-te el pas.
- **Rodamón**: va a l'atzar.

Fet com a prova del centre de control d'rm amb Claude Code.
